# Джарвис — голосовой ассистент для Windows 11

Пользователь говорит по-русски, ассистент выполняет действия на компьютере и отвечает голосом.
Техническое задание — в [spec.md](spec.md).

Фраза обрабатывается двумя путями:

1. **Локально, без нейросети.** Фраза нормализуется и сравнивается с командами из YAML-файлов
   в папке `commands/`. Так работают повседневные команды: «открой ютуб», «сделай громче»,
   «пауза», «сверни все окна». Этот путь работает без интернета.
2. **Через нейросеть.** Если локально ничего не нашлось или совпадение неоднозначно,
   фраза уходит агенту нейросети: он сам вызывает нужные действия и коротко отвечает
   голосом. Например, «создай на рабочем столе папку Проекты» или «сколько места
   свободно на диске C».

## Статус

| Этап | Что входит | Готово |
|---|---|---|
| 1. Каркас | конфиг, логирование, реестр действий, YAML-команды, матчер, ввод фраз текстом, тесты | ✅ |
| 2. Голос | микрофон, VAD, слово активации, push-to-talk, Whisper, озвучка, голосовое подтверждение | ✅ |
| 3. Нейросеть | LLM-агент с инструментами, политика безопасности, замеры задержек | ✅ |
| 4. Интерфейс | главное окно, настройки (в том числе нейросети и ключа API), оверлей, быстрый чат, трей, горячая перезагрузка команд | ✅ |
| 5. Расширения | редактор команд, история, работа с экраном, таймеры, автозапуск, exe | ✅ |

Ассистент живёт в трее. У него есть главное окно (статус, громкость, нейросеть, последние
команды, настройки), плашка-оверлей внизу экрана — что услышал и что делает — и окно
быстрого чата для команд текстом. Если окна запустить нельзя (например, нет WebView2),
ассистент работает в консоли, как на прошлых этапах.

## Установка

Два способа: готовая сборка (Jarvis.exe — ничего ставить не нужно) или запуск из исходников.

### Готовая сборка

1. Откройте [Actions](https://github.com/TyMaxiss/jarvis/actions) → последний успешный запуск
   «Тесты» ветки `claude/zen-bell-h1k6tu` → внизу, в **Artifacts**, скачайте `Jarvis-win-x64`
   (нужно войти в GitHub; архив хранится 14 дней).
2. До распаковки: правый щелчок по архиву → «Свойства» → «Разблокировать» → OK. Иначе файлы
   останутся помеченными «из интернета»: SmartScreen будет спрашивать при запуске.
3. Распакуйте папку `Jarvis` туда, где можно писать (например, в `C:\Users\<вы>\Jarvis`, но не
   в `Program Files`): рядом с программой хранятся настройки, модели и логи.
4. Запустите `Jarvis.exe`.

При первом запуске ассистент сам скачивает всё, что нужно голосу (нужен интернет). Ход загрузки
виден на главной, а команды текстом работают сразу:

- модель Vosk для обращения по имени — 45 МБ;
- русский голос Piper — 60 МБ (пока он качается, ассистент говорит голосом Windows);
- модель Whisper для распознавания речи: `small` (~480 МБ) или, для видеокарты NVIDIA,
  `large-v3-turbo` (~1,6 ГБ);
- только с видеокартой NVIDIA — библиотеки CUDA 12 и cuDNN 9, без которых Whisper не работает
  на видеокарте: около 1,3 ГБ (на диске — около 2 ГБ, в папке `cuda` рядом с `Jarvis.exe`).
  Это официальные пакеты NVIDIA с PyPI — те же, что ставит `uv sync --extra cuda`; ассистент
  сверяет их контрольные суммы.

Всё скачивается один раз. Если закрыть ассистента посередине, при следующем запуске загрузка
продолжится с того же места, а если она не удалась (нет интернета), ассистент работает с тем,
что есть, и пробует снова при следующем запуске. Дальше всё работает без интернета. Скачать
всё заранее: в этой папке откройте терминал (правый щелчок → «Открыть в терминале») и
выполните `.\JarvisConsole.exe --download-models`.

В папке: `Jarvis.exe` — ассистент с окнами (без консоли), `JarvisConsole.exe` — то же
с консолью (режим `--console`, `--download-models`, `--self-check`), `_internal` — библиотеки.
При первом запуске рядом появляются `config.yaml`, `commands/my.yaml`, `logs/` и `models/`.
Новую версию распакуйте поверх старой: настройки, ключи, свои команды, модели и библиотеки
CUDA останутся — их в сборке нет.

### Из исходников

Нужны Windows 10/11 x64 и [uv](https://docs.astral.sh/uv/) — менеджер Python-проектов.
Python 3.12 uv скачает сам.

1. Установите uv (PowerShell):
   ```powershell
   powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
   ```
   После установки откройте новое окно терминала.
2. Скачайте проект. С установленным [Git](https://git-scm.com/download/win):
   ```powershell
   git clone -b claude/zen-bell-h1k6tu https://github.com/TyMaxiss/jarvis.git
   cd jarvis
   ```
   Без Git: на странице репозитория выберите ветку `claude/zen-bell-h1k6tu`,
   нажмите **Code → Download ZIP** и распакуйте архив.
3. Установите зависимости:
   ```powershell
   uv sync
   ```
4. Модели для голоса ассистент скачает сам при первом запуске (нужен интернет) в папку
   `models/`:
   - модель Vosk для слова активации — `vosk-model-small-ru-0.22`, 45 МБ;
   - русский голос Piper — `ru_RU-dmitri-medium`, 60 МБ;
   - модель Whisper для распознавания: `small` (~480 МБ) для процессора
     или `large-v3-turbo` (~1,6 ГБ) для видеокарты NVIDIA.

   Скачать их заранее:
   ```powershell
   uv run python -m assistant --download-models
   ```
   Если скачать не удалось, ассистент работает с тем, что есть, и пробует снова при
   следующем запуске. Вручную модели берутся здесь:
   Vosk — [alphacephei.com/vosk/models](https://alphacephei.com/vosk/models) (распаковать в `models/`),
   голос Piper — [huggingface.co/rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU)
   (файлы `.onnx` и `.onnx.json` положить в `models/piper/`).

   После скачивания всё работает без интернета.

Для окон нужен Microsoft Edge WebView2 Runtime. В Windows 11 он уже есть. Если его нет,
ассистент при запуске предложит открыть
[страницу загрузки](https://developer.microsoft.com/microsoft-edge/webview2/consumer/), а пока
будет работать в консоли.

## Запуск

```powershell
uv run python -m assistant
```

Откроется главное окно, а рядом с часами появится значок ассистента. Кнопка «закрыть»
в окне сворачивает ассистента в трей; совсем выйти — «Выход» в меню значка.

Чтобы ассистент запускался вместе с Windows, включите «Настройки → Интерфейс → Запускать
вместе с Windows»: в папке «Автозагрузка» (`shell:startup`) появится ярлык «Джарвис», и при
входе в Windows ассистент сразу свернётся в трей, без окна терминала. Выключатель удаляет ярлык.

Ассистент работает в одном экземпляре: повторный запуск показывает окно уже работающего
и завершается (в консоли — сообщение). Два экземпляра слушали бы один микрофон и отвечали
бы хором.

| Ключ | Что делает |
|---|---|
| без ключей | окна, значок в трее и голос |
| `--console` | консольный режим вместо окон: ввод фраз текстом, всё происходящее — в консоли |
| `--text` | без микрофона и озвучки |
| `--dry-run` | действия только пишутся в журнал, ничего не выполняется |
| `--debug` | подробный лог прямо в консоли |
| `--list-devices` | список микрофонов |
| `--download-models` | скачать заранее всё для голоса (иначе скачается при первом запуске) |
| `--download-cuda` | скачать библиотеки CUDA для Whisper на видеокарте NVIDIA в папку `cuda` и проверить, что они загружаются |
| `--autostart` | сразу свернуться в трей (так запускает ярлык автозапуска) |
| `--self-check` | проверить, что загружаются все части программы (Vosk, Whisper, Piper, звук, окна, UI Automation, SAPI), и выйти |

Ключи можно сочетать: `uv run python -m assistant --dry-run --debug`. У сборки ключи те же:
`Jarvis.exe --dry-run`, а консольный режим — `JarvisConsole.exe --console`.

При первом запуске рядом создаётся `config.yaml` (копия `config.example.yaml`).

## Интерфейс

**Главная.** Большая кнопка микрофона (то же, что горячая клавиша), статус («Жду
«Джарвис»», «Слушаю…», «Выполняю…»), кнопка паузы прослушивания, громкость системы,
текущая нейросеть, быстрые сценарии и последние команды: что сказано, ответ, выполнено ли
локально или нейросетью и за сколько. Сценарий — команда из нескольких шагов без слотов
(например, «рабочий режим» из примера в `commands/my.yaml`); он запускается кнопкой.
Поставленные таймеры и напоминания видны в отдельной карточке с обратным отсчётом;
× — отменить.

**Команды** — редактор YAML-команд. Слева паки (свой `my.yaml` — первым) и поиск, справа
команда: фразы чипами (Enter — добавить), слоты с типами, условие по окну и программе,
шаги карточками — действие из списка по группам и поля его параметров, ответ,
подтверждение, горячая клавиша. «Проверить фразу» показывает, какая команда сработает,
с какой оценкой и значениями слотов — по несохранённому черновику; «Выполнить» запускает
черновик; «Сохранить» записывает команду в YAML: остальной файл с комментариями не
меняется. Встроенную команду редактор сохраняет копией в `my.yaml` — с тем же `id` она
заменяет встроенную, а сами встроенные паки не трогаются.

**История** — всё, что вы говорили и печатали, по дням: фраза, откуда пришла (голос, текст,
горячая клавиша), куда ушла (команда или нейросеть), ответ, причина ошибки и действия —
с аргументами, итогом и временем. Фильтры «Ошибки», «Нейросеть», «Команды» и поиск.
«Повторить» выполняет фразу снова, «Сохранить как команду» открывает редактор с фразой и
шагами, которые выполнила нейросеть: удачная задача становится командой без нейросети.
История строится по журналу `logs/actions.jsonl`.

**Настройки.** Нейросеть (провайдер, ключ, модель — см. «Нейросеть»), микрофон с индикатором
уровня, обращение по имени и его чувствительность, горячие клавиши (новое сочетание
записывается нажатием), модель распознавания и устройство, голос ассистента с кнопкой
«Прослушать», скорость и громкость речи, тема и акцентный цвет, оверлей, режим dry-run,
автозапуск вместе с Windows, кнопки «открыть config.yaml / папку команд / лог / журнал».
Изменения сохраняются сразу в `config.yaml` (комментарии в нём остаются). Тема, оверлей,
dry-run, нейросеть и громкость речи применяются сразу; голос, распознавание и озвучка —
после перезапуска: появится кнопка «Перезапустить».

**Оверлей** — плашка внизу по центру экрана. Появляется, когда ассистент слушает
(с «волной» по уровню микрофона), показывает распознанную фразу, шаги («Шаг 2 из 3 ·
Открываю Блокнот») и ответ и прячется через 3 секунды после конца команды. Фокус она не
забирает: можно продолжать печатать в своём окне. Если действие требует подтверждения,
на ней появляются кнопки «Да / Нет» — можно ответить и голосом.

**Быстрый чат** — **Ctrl+Alt+Enter**: окно с полем ввода поверх всех окон. Фраза
выполняется так же, как сказанная голосом. Enter — выполнить, Esc — закрыть,
↑ — повторить прошлую команду.

**Значок в трее**: открыть окно, быстрый чат, пауза прослушивания, перечитать команды,
открыть `config.yaml` и лог, выход.

**Горячие клавиши**: Ctrl+Alt+Пробел — слушать команду, Ctrl+Alt+Q — прервать ответ и
задачу нейросети, Ctrl+Alt+Enter — быстрый чат. Поменять — в настройках. Команде из YAML
можно дать своё сочетание полем `hotkey` (см. «Как добавить свою команду»).

**Команды перечитываются сами**: через секунду после сохранения файла в `commands/`.
Ошибки в командах показываются уведомлением в окне.

### Как изменить интерфейс

Интерфейс — React + TypeScript + Tailwind в папке `ui/`. Готовая сборка лежит в `ui/dist`,
поэтому для запуска ассистента Node.js не нужен. Чтобы менять интерфейс, нужен
[Node.js](https://nodejs.org) 22:

```powershell
cd ui
npm ci
npm run dev            # сервер разработки с мгновенным обновлением страницы
```

В другом окне: `$env:JARVIS_UI_URL = "http://localhost:5173"; uv run python -m assistant` —
окна откроют страницу с сервера разработки. Страницу можно открыть и в обычном браузере
с подделкой Python: `http://localhost:5173/?mock` (оверлей — `?view=overlay&mock`,
чат — `?view=chat&mock`). После правок — `npm run build` и закоммитьте `ui/dist`
(CI проверяет, что сборка свежая).

## Голос

Как обратиться к ассистенту:

- **По имени.** «Джарвис, открой ютуб» одной фразой. Можно сказать «Джарвис», дождаться
  короткого сигнала и потом сказать команду.
- **Горячей клавишей Ctrl+Alt+Пробел.** Нажмите сочетание, дождитесь сигнала и говорите.
  Конец фразы определяется по паузе. В `config.yaml` можно включить режим удержания
  (`push_to_talk_mode: hold`): тогда говорите, пока держите клавиши.
- **Командой `:listen`** в консоли — то же, что горячая клавиша.

После выполненной команды ассистент ещё 5 секунд слушает продолжение без имени:
«сделай громче» → «ещё громче». Если команда не понята («Не знаю такой команды»), он сразу
снова ждёт имя. Когда ассистент перестаёт слушать, оверлей прячется, а на главной снова
«Жду «Джарвис»».
Пока ассистент говорит, имя и команды не слушаются, чтобы он не услышал сам себя.
Слушаются только «стоп», «отмена», «хватит»: они обрывают ответ, как и **Ctrl+Alt+Q**.

С ключом `--dry-run` команды распознаются, но не выполняются — только пишутся в журнал.

Если команда требует подтверждения, ассистент спросит голосом и покажет кнопки «Да / Нет»
в оверлее. Ответьте «да» или «подтверждаю» (или «нет», «отмена») либо нажмите кнопку.
Молчание 5 секунд означает отмену (после него кнопку ещё можно нажать 3 секунды). Согласие
засчитывается, только если ответ — одно из слов «да», «подтверждаю», «конечно»,
«выполняй» без посторонних слов: фраза вроде «хорошая погода» согласием не считается.
Так же подтверждаются рискованные действия, которые выбрала нейросеть (см. «Безопасность»).

Что происходит внутри:
1. Микрофон пишется блоками по 32 мс.
2. Детектор речи Silero VAD отмечает, где говорят.
3. Пока имя не прозвучало, звук получает только маленький распознаватель Vosk, ищущий
   слово «джарвис» среди частых слов русской речи — без них Vosk принимал за имя обычную речь.
   В тишине процессор почти не нагружается. Имя засчитывается, только если Vosk в нём
   уверен (`voice.wake_confidence`).
4. Если прозвучало только имя (короткая речь), ассистент сразу подаёт сигнал и ждёт команду.
5. Иначе фраза целиком распознаётся Whisper. Если в тексте нет имени, это было ложное
   срабатывание, и фраза пропускается. Иначе она обрабатывается так же, как введённая текстом.

Скорость распознавания зависит от железа. На процессоре (`small`) в CI, на виртуальной
машине GitHub с 4 виртуальными процессорами, фраза распознаётся за 3–5 с (машины разные).
На видеокарте NVIDIA (`large-v3-turbo`) — ориентировочно 0,2–0,5 с, и распознаёт она
заметно точнее. `stt.model: base` быстрее, но по-русски ошибается заметно чаще.

После каждой голосовой команды в лог (а в консольном режиме — и в консоль) пишется время
от конца речи до результата:
«950 мс от конца речи: пауза 700 + распознавание 220 + выполнение 30». Пауза — это
`voice.min_silence_ms`: столько тишины ассистент ждёт, чтобы понять, что фраза закончена.
Её можно уменьшить до 500, но тогда фраза может оборваться, если сделать паузу посередине.
Те же задержки пишутся в лог.

### Видеокарта NVIDIA

Whisper на видеокарте нужны библиотеки CUDA 12 и cuDNN 9. Сборка `Jarvis.exe` скачивает
их сама при первом запуске (около 1,3 ГБ — в папку `cuda` рядом с собой). Из исходников
проще всего поставить их из pip:

```powershell
uv sync --extra cuda
```

Дальше обновляйте зависимости тоже командой `uv sync --extra cuda`: обычный `uv sync`
удалит эти библиотеки. При запуске ассистент пишет в консоли, где работает распознавание:
«Распознавание речи: Whisper large-v3-turbo на видеокарте».

Видеокарты RTX 50 (Blackwell): готовых ядер под них в CTranslate2 (на нём работает
faster-whisper) нет, драйвер NVIDIA собирает их из универсального кода PTX. Поэтому
нужен свежий драйвер, а первый запуск на видеокарте может занять больше времени —
дальше драйвер берёт ядра из своего кэша.

При старте ассистент сам проверит видеокарту. Если библиотек CUDA нет (а сборке не удалось
их скачать), он сразу распознаёт на процессоре, не загружая большую модель впустую, и пишет,
что сделать. Если CUDA не запустится по другой причине, он покажет её и тоже продолжит
на процессоре.

| Фраза | Что произойдёт |

| `переключись на блокнот` / `закрой блокнот` | переключение / закрытие окна |
| `сверни все окна` / `разверни все окна`, `разверни окно` | управление окнами |
| `напечатай Привет, мир!` | печать текста (кириллица поддерживается) |
| `который час` | время и дата |

| `открой загрузки` / `открой документы` | папка в проводнике |

| `нажми на кнопку Сохранить` / `кликни по ссылке Войти` | нажать элемент активного окна по названию |

Служебные команды консоли (режим `--console`):

| Команда | Что делает |
|---|---|
| `:check <фраза>` | показать, какая команда сработает и с какой оценкой, без выполнения |
| `:delay 3` | ждать 3 секунды перед выполнением, чтобы успеть переключиться в нужное окно (например, в браузер с YouTube) |
| `:reload` | перечитать YAML-команды без перезапуска |
| `:commands`, `:apps [текст]`, `:windows` | списки команд, найденных приложений, открытых окон |
| `:listen` | начать слушать голосовую команду (как Ctrl+Alt+Пробел) |
| `:forget` | забыть разговор с нейросетью |
| `:q` | выход |

## Таймеры и напоминания

- Фразы: «поставь таймер на 5 минут», «засеки 30 секунд», «таймер на два часа», «напомни
  через 10 минут позвонить маме», «напомни через час проверить духовку», «какие таймеры»,
  «отмени таймер», «отмени все таймеры». Сложное — «напомни завтра в девять позвонить
  врачу», «таймер на полторы минуты для чая» — понимает нейросеть: у неё те же действия.
- Когда время вышло: сигнал, голос («Таймер на 5 минут: время вышло»), уведомление в окне
  (висит, пока его не закроют) и уведомление Windows.
- Список хранится в `timers.json` рядом с `config.yaml`, поэтому переживает перезапуск. Что
  сработало, пока ассистент был закрыт, он объявит при запуске: «Пока программа была
  закрыта, в 18:30 сработало: …». Время сверяется с часами, так что сон компьютера не
  сбивает напоминание «в 18:30».

## Экран: что на нём и как нажать

- **Нажать по названию.** «Нажми на кнопку Сохранить», «кликни по ссылке Войти», «щёлкни на
  Файл» — ассистент находит элемент в активном окне через UI Automation (без координат) и
  нажимает: кнопку, ссылку, пункт меню, вкладку, флажок, поле. Название ищется нечётко:
  «сохранит» найдёт «Сохранить», а «сохранить» — именно «Сохранить», а не «Сохранить как…».
  Просто «нажми …» уходит нейросети: «нажми энтер» — это клавиша, а не кнопка.
- **Что на экране** — для нейросети: «что у меня на экране?», «нажми в блокноте Файл, потом
  Сохранить как». Действие `describe_screen` даёт ей заголовок активного окна, его видимые
  элементы (тип, название, где они) и снимок экрана, уменьшенный до 1280 пикселей по ширине.
  Сам снимок получают модели, которые понимают картинки (`vision: true` в профиле: DeepSeek,
  ChatGPT, Claude); остальные (Ollama, Zen) работают с текстовым описанием. Координаты
  в описании — в пикселях снимка, а `click_screen` переводит их обратно в пиксели экрана:
  так нейросеть может нажать и то, чего нет среди элементов (например, внутри картинки).
- Если активно окно самого ассистента (быстрый чат, консоль), работа идёт с окном под ним.
- Снимок экрана уходит провайдеру нейросети, как и текст ваших просьб. Окна программ,
  запущенных от администратора, ассистент без прав администратора не нажимает.

## Нейросеть

Фразы, которых нет среди команд, получает агент нейросети. Ему доступны те же действия,
что и YAML-командам (таблица «Действия» ниже), кроме `say`: его ответ и так озвучивается.
Агент вызывает действия по одному или несколько сразу, видит их результат и отвечает
одним-двумя предложениями. Озвучка начинается с первого готового предложения, не дожидаясь
конца ответа.

Примеры:

| Фраза | Что сделает агент |
|---|---|
| `создай на рабочем столе папку Проекты и открой её` | `create_folder`, затем `open_folder` |
| `открой блокнот и напиши список покупок: хлеб, молоко` | `open_app`, `wait`, `type_text` |
| `сколько места свободно на диске C` | спросит подтверждение и выполнит команду PowerShell |
| `скопируй в буфер мой адрес почты example@mail.ru` | `clipboard_set` |
| `расскажи анекдот` | просто ответит голосом |

### Выбор провайдера

Проще всего — в окне: **Настройки → Нейросеть**.
1. Выберите провайдера: DeepSeek, ChatGPT, Claude, Ollama, OpenCode Zen или «Другой сервис»
   (любой с OpenAI-совместимым API: укажите его адрес).
2. Вставьте ключ API. «Где взять ключ» откроет страницу провайдера.
3. Выберите модель из списка (кнопка ⟳ загрузит все модели, доступные по ключу) или впишите свою.
4. «Проверить» отправит короткий запрос с инструментом — такой же, как в настоящей задаче,
   — и покажет время ответа или понятную ошибку.
5. «Использовать …» сохранит выбор: нейросеть переключится сразу, без перезапуска.

Ключ записывается в `.env` рядом с `config.yaml`. В окне после сохранения видны только его
последние четыре символа, в логи он не попадает; кнопка 🗑 удаляет его с компьютера.
Ключ из `.env` важнее одноимённой переменной окружения Windows. Если ключ есть только
в переменной Windows, плитка подписана «ключ из Windows».

Как выглядят ключи (в поле ввода есть подсказка):

| Сервис | Ключ начинается с | Где создать |
|---|---|---|
| Claude | `sk-ant-api03-` (около 100 символов) | [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys) |
| ChatGPT | `sk-proj-` | [platform.openai.com/settings/organization/api-keys](https://platform.openai.com/settings/organization/api-keys) |
| DeepSeek | `sk-` (и 32 символа) | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) |

Целиком ключ показывается только один раз, при создании; в списке ключей видна сокращённая
запись с «…» — она не подойдёт. Подписка Claude Pro или Max не даёт ключа API: API
оплачивается отдельно, в Claude Console. Токен подписки из Claude Code (`sk-ant-oat…`) — не
ключ API. Если сервис не принял ключ, «Проверить» покажет его ответ и подскажет, что не так:
например, что вставлен ключ другого сервиса. Адрес Claude берётся из профиля, а не из
переменной `ANTHROPIC_BASE_URL`: её ставят, чтобы пустить Claude Code через другой сервис.

Нейросеть подключается через профиль (`llm.profile` в `config.yaml`). Встроены:

| Профиль | Модель | Ключ в `.env` | Что нужно знать |
|---|---|---|---|
| `deepseek` | `deepseek-flash` | `DEEPSEEK_API_KEY` | выбран по умолчанию; платно, но недорого; нужен интернет. Режим рассуждений выключен — так быстрее |
| `openai` (ChatGPT) | `gpt-6-luna` | `OPENAI_API_KEY` | платно. Запросы идут без рассуждений (`effort: none`): только так модели OpenAI вызывают действия в Chat Completions. Ещё подходят `gpt-5.4-mini`, `gpt-6-sol`, `gpt-5.5`; `gpt-6-astra` и `gpt-6.1-sol` вызывают действия только через Responses API, которого у ассистента пока нет |
| `anthropic` | `claude-opus-5-5` | `ANTHROPIC_API_KEY` | Claude через официальный SDK `anthropic`; платно. Рассуждения у этой модели не выключаются — стоит минимальный уровень (`effort: low`). Быстрее и дешевле отвечает `claude-haiku-5-5` |
| `ollama` | `qwen3:8b` | не нужен | бесплатно и без интернета: модель работает на вашем компьютере через [Ollama](https://ollama.com) |
| `opencode_zen` | `deepseek-v4-flash-free` | `OPENCODE_API_KEY` | бесплатные модели сейчас недоступны другим программам (см. ниже) |

**OpenCode Zen.** С сентября 2026 бесплатные модели Zen (с `-free` в названии) работают только
в приложении OpenCode, а другим программам отвечают ошибкой 403 FreeTierError. Ассистент
предупреждает об этом при старте, а при ошибке пишет причину в консоли. Обходить это ограничение
он не пытается. Платная модель Zen работает по ключу: укажите её в `llm.profiles.opencode_zen.model`.

Где взять ключ: DeepSeek — [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
(сначала пополните баланс), ChatGPT —
[platform.openai.com/settings/organization/api-keys](https://platform.openai.com/settings/organization/api-keys),
Claude — [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys).

**Вручную, без окна** (то же для любого профиля), на примере DeepSeek:
1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com), пополните баланс
   и создайте ключ в разделе [API keys](https://platform.deepseek.com/api_keys).
2. Скопируйте `.env.example` в `.env` (рядом с `config.yaml`) и впишите ключ:
   `DEEPSEEK_API_KEY=sk-...`
3. В `config.yaml` укажите профиль:
   ```yaml
   llm:
     profile: deepseek
   ```

**Ollama (без интернета):**
1. Установите Ollama: [ollama.com/download](https://ollama.com/download). После установки она
   работает в фоне.
2. Скачайте модель (около 5 ГБ): `ollama pull qwen3:8b`
3. В `config.yaml`: `llm:` → `profile: ollama`.

Модель занимает около 5 ГБ памяти видеокарты. Вместе с Whisper `large-v3-turbo` на видеокарте
с 8 ГБ может быть тесно: тогда Ollama держит часть модели в оперативной памяти и отвечает
медленнее. Модель поменьше — `qwen3:4b` (`llm.profiles.ollama.model: qwen3:4b`). Небольшие
локальные модели хуже выбирают действия, чем DeepSeek.

**Другой провайдер.** Подойдёт любой сервис с OpenAI-совместимым API. Добавьте профиль и
впишите ключ в `.env` (в логах он маскируется):

```yaml
llm:
  profile: my
  profiles:
    my:
      base_url: https://api.example.com/v1
      model: название-модели
      api_key_env: MY_API_KEY      # имя переменной в .env
```

### Как ведёт себя агент

- Одна просьба — не больше 15 обращений к нейросети и 120 секунд (`llm.max_steps`,
  `llm.timeout`). Если не уложился, ассистент так и скажет.
- Ошибки сети, таймауты и 429 повторяются ещё 2 раза с нарастающей паузой. Если не помогло,
  ассистент говорит «Нейросеть недоступна», а в консоли пишет причину. Команды из YAML при этом
  работают как обычно.
- Разговор помнится: последние 10 обменов, поэтому можно продолжать: «создай на рабочем
  столе папку Проекты» → «а теперь открой её».
  После 5 минут тишины или команды `:forget` разговор забывается.
- В системной подсказке — дата, время и активное окно. Текст с экрана, веб-страниц и
  из файлов нейросеть считает данными, а не командами.
- Прервать задачу: голосом «стоп», «отмена» или «хватит» (можно с именем: «Джарвис, стоп»),
  горячей клавишей Ctrl+Alt+Q, в консоли — Ctrl+C. «Стоп» засчитывается, только если сказано
  отдельно: «стоп» посреди другой фразы задачу не прерывает.
- В консоли видно каждое действие и итог: `[нейросеть] шаг 1: ✓ open_app(name='Блокнот') →
  Открываю Блокнот`, затем `[нейросеть] ответила: запросов 2, нейросеть 1840 мс, всего 2300 мс`.
  В логе — время до первого токена каждого запроса.

## Безопасность

У каждого действия есть уровень риска:
- **без вопросов** — большинство действий;
- **с подтверждением** — `sleep`, `shutdown`, `restart`, `run_shell` (всегда), а также
  `close_app` с `force: true` и `write_file`, если файл уже есть. Ассистент спрашивает голосом
  и кнопками «Да / Нет» в окне (для фраз из быстрого чата — только кнопками; в консольном
  режиме — в консоли); молчание — отмена;
- **запрещено** — не выполняется никогда, а нейросеть получает отказ с причиной.

Для `run_shell` запрещены опасные команды: форматирование и разметка дисков (`format`,
`Format-Volume`, `diskpart`, `Clear-Disk`…), рекурсивное удаление (`del /s`, `rd /s`,
`Remove-Item -Recurse`, `rm -r`), удаление из реестра (`reg delete`, `Remove-Item HKLM:…`),
`bcdedit`, `vssadmin`, `wbadmin delete`, `cipher /w`, `sdelete` и закодированные команды
(`powershell -enc`). Каждая часть конвейера (`|`, `;`, `&`) проверяется отдельно.

С `--dry-run` действия нейросети тоже только пишутся в журнал. Все правила — в
`assistant/safety/policy.py`.

## Настройка (`config.yaml`)

Все параметры описаны комментариями в `config.example.yaml`. Главное:

```yaml
general:
  name: джарвис              # имя ассистента, оно же слово активации
  dry_run: false             # true — ничего не выполнять, только писать в журнал
  debug: false               # true — в лог пишутся топ-3 кандидата матчера

matcher:
  threshold: 85              # минимальная оценка совпадения фразы с командой (0–100)
  ambiguity_gap: 5           # если два лучших кандидата ближе — фраза уходит в нейросеть

apps:
  aliases:                   # разговорное название → программа, путь или URI
    телега: Telegram
    хром: Google Chrome
    блокнот: notepad.exe
    параметры: "ms-settings:"

browser:
  search_url: "https://www.google.com/search?q={query}"   # можно заменить на Яндекс

llm:
  profile: deepseek          # deepseek, openai, anthropic, ollama, opencode_zen или свой (см. «Нейросеть»)

ui:
  theme: dark                # dark или light
  overlay: true              # плашка внизу экрана
  quick_chat_key: ctrl+alt+enter
  start_minimized: false     # true — сразу в трей (ярлык автозапуска делает так и без этого)
```

Большую часть этого проще менять в окне: «Настройки».

Ключи API хранятся в файле `.env` — скопируйте `.env.example`. `.env` не попадает в git,
ключи маскируются в логах.

## Как добавить свою команду

Свои команды пишите в `commands/my.yaml`: он загружается последним, и команда с тем же `id`,
что у встроенной, заменяет её. Ассистент перечитает файл сам через секунду после сохранения.

```yaml
# Простая команда: несколько фраз, один шаг.
- id: minimize_all
  phrases: ["сверни все окна", "покажи рабочий стол"]
  steps:
    - hotkey: {keys: "win+d"}

# Слот: число из фразы подставляется в шаг. «громкость на пятьдесят» → 50.
- id: volume_set
  phrases: ["громкость на {percent}", "поставь громкость {percent}"]
  slots: {percent: int}          # int, float, str (по умолчанию) или text — см. ниже
  reply: "Громкость {percent}"   # что ответить после выполнения
  steps:
    - volume_set: {percent: "{percent}"}

# Условие: команда работает, только когда активно окно с YouTube в заголовке.
# Такие команды важнее обычных с той же фразой.
- id: youtube_pause
  phrases: ["пауза", "стоп"]
  when: {active_window_contains: "YouTube"}   # или active_process: "chrome.exe"
  steps:
    - hotkey: {keys: "k"}

# Сценарий из нескольких шагов.
- id: work_mode
  phrases: ["рабочий режим"]
  reply: "Все системы готовы"
  steps:
    - open_app: {name: "Telegram"}
    - open_app: {name: "Visual Studio Code"}
    - volume_set: {percent: 30}

# Своя горячая клавиша: команда запускается и без фразы.
- id: mute_toggle
  phrases: ["выключи звук"]
  hotkey: ctrl+alt+m
  steps:
    - mute: {}

# Подтверждение перед выполнением.
- id: close_all_chrome
  phrases: ["закрой все окна хрома"]
  confirm: true
  steps:
    - close_app: {name: "Google Chrome"}
```

Поля команды:

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | уникальное имя |
| `phrases` | да* | фразы; `{слот}` — переменная часть |
| `steps` | да | действия по порядку (см. список ниже) |
| `slots` | нет | типы слотов: `int`, `float`, `str` (по умолчанию; знаки препинания в конце убираются) или `text` (текст как сказан, с пунктуацией — для диктовки) |
| `when` | нет | условие по активному окну: `active_window_contains`, `active_process` (строка или список) |
| `confirm` | нет | спросить подтверждение перед выполнением |
| `reply` | нет | ответ после выполнения; `{result}` — итог последнего шага, `{слот}` — значение слота |
| `hotkey` | нет | запуск по горячей клавише, например `ctrl+alt+m` (в оконном режиме; у команды не должно быть слотов); *можно вместо `phrases` |

Ошибочная команда (неизвестное действие, неверный параметр) пропускается, а в окне
(уведомлением), в консоли и в логе выводится файл, строка и причина.

Как ищется команда:
- фразы сравниваются нечётко, поэтому «сделай погромче» найдёт «сделай громче»;
- точное совпадение побеждает сразу;
- если два лучших варианта ближе 5 пунктов, фраза считается неоднозначной;
- фраза «открой ютуб и сделай громче» делится по «и», «потом», «а затем»; если какая-то
  часть не нашлась («открой блокнот и напиши привет»), вся фраза уходит в нейросеть.
  Союз внутри запроса не мешает: «найди на ютубе кошки и собаки» — один поиск;
- из шаблонов со слотами выбирается самый конкретный: «найди на ютубе {query}» важнее, чем «найди {query}».

## Логи и журнал

- `logs/assistant.log` — лог программы. С `--debug` или `debug: true` в нём есть
  топ-3 кандидата матчера для каждой фразы и задержки.
- `logs/actions.jsonl` — журнал всех действий: время, источник (`local` — команда из YAML,
  `llm` — выбрала нейросеть), команда, фраза, действие, аргументы, результат, длительность;
  для каждой фразы — куда она ушла, ответ и итог. По нему строится «История» в окне.

## Права администратора

По умолчанию ассистент запускается без прав администратора. Из-за защиты Windows (UIPI)
он не может нажимать клавиши и печатать в окна программ, запущенных **от администратора**
(например, диспетчер задач или терминал «от имени администратора»). Когда такое окно
активно, не срабатывают и горячие клавиши ассистента. Если это нужно, запускайте
ассистента тоже от администратора.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| «Окна недоступны: нет Microsoft Edge WebView2 Runtime» | установите его со [страницы загрузки](https://developer.microsoft.com/microsoft-edge/webview2/consumer/) и запустите ассистента заново |
| «Окна недоступны: интерфейс не собран» | в проекте нет `ui/dist`: скачайте проект заново или соберите интерфейс (`cd ui; npm ci; npm run build`, нужен Node.js) |
| Окно открылось пустым | обновите WebView2 (ссылка выше); подробности — в `logs/assistant.log` |
| «Быстрый чат: сочетание … уже занято» | выберите другое в «Настройки → Горячие клавиши» |
| Оверлей не появляется | он показывается только для голосовых команд; проверьте «Настройки → Интерфейс → Оверлей» |
| «Не удалось скачать модель Vosk», «… голос Piper», «… библиотеки CUDA» | нет интернета или загрузку блокирует прокси, антивирус, нехватка места на диске (причина — в сообщении). При следующем запуске ассистент попробует снова; можно и сразу: `uv run python -m assistant --download-models` (в сборке — `JarvisConsole.exe --download-models`) |
| «Ассистент уже запущен» | он работает в трее — повторный запуск показывает его окно; совсем выйти — «Выход» в меню значка |
| «Не нашёл «…» в окне» (нажатие по названию) | скажите название, как оно написано в окне; ассистент перечислит похожие. Некоторые программы (игры, часть окон на Qt) не сообщают элементы UI Automation — тогда поможет нейросеть со снимком экрана |
| Сборка: «Windows защитил ваш компьютер» | «Подробнее → Выполнить в любом случае», или до распаковки разблокируйте архив в его свойствах |
| Сборка: окна не открываются | `JarvisConsole.exe --self-check` покажет, какая часть не загрузилась; если архив не был разблокирован — разблокируйте и распакуйте заново |
| «Голос недоступен: не удалось открыть микрофон» | проверьте, что микрофон подключён и разрешён в «Параметры → Конфиденциальность → Микрофон»; выберите его в `voice.input_device` (список — `--list-devices`) |
| Не реагирует на имя | говорите громче и чётче, проверьте микрофон; уменьшите `voice.wake_confidence` (например, до 0.6); попробуйте Ctrl+Alt+Пробел |
| Срабатывает сам по себе | увеличьте `voice.wake_confidence` до 0.9; не выключайте `voice.verify_wake_word`; в крайнем случае отключите `voice.wake_word` и пользуйтесь горячей клавишей |
| Обрезает конец фразы | увеличьте `voice.min_silence_ms` до 1000 |
| Долго распознаёт | видеокарта (`uv sync --extra cuda`) или `stt.model: base` (быстрее, но с ошибками) |
| В логе «Русский голос SAPI не найден» | это запасная озвучка, основная — Piper (скачивается при первом запуске). Для русского голоса Windows добавьте русский язык с функцией «Преобразование текста в речь»: «Параметры → Время и язык → Язык и регион» |
| Ассистент слышит сам себя | говорите в гарнитуру или уменьшите громкость колонок |
| «api.anthropic.com не принял ключ API» (или другой сервис) | следуйте подсказке после ответа сервиса. Ключ Claude начинается с `sk-ant-api03-` и создаётся в [Claude Console](https://platform.claude.com/settings/keys); сокращённая запись с «…» и токен подписки `sk-ant-oat…` не подойдут. Ключ должен быть вставлен в плитку своего сервиса |
| «Видеокарта NVIDIA не используется: нет библиотек CUDA» | из исходников — `uv sync --extra cuda` и перезапуск (обычный `uv sync` эти библиотеки удаляет). Сборка скачивает их сама; если не скачались, причина — в сообщении, а при следующем запуске будет новая попытка (или `JarvisConsole.exe --download-cuda`). Если видеокарта не нужна — выберите в настройках распознавания «Процессор» (`stt.device: cpu`): тогда сообщения не будет и библиотеки не скачиваются |
| «Нейросеть недоступна» | нажмите «Проверить» в «Настройки → Нейросеть» — там будет причина (в консольном режиме — строка `[нейросеть] недоступна: …`). «нет ключа API» — вставьте ключ; «403 FreeTierError» — бесплатные модели OpenCode Zen, выберите другой профиль; «нет связи с http://localhost:11434» — запустите Ollama; «402» — пополните баланс у провайдера; «вызывает действия только через Responses API» — выберите другую модель ChatGPT |
| «Стоп» не прерывает | скажите его отдельной фразой, без других слов, или «хватит», «отмена» — их Vosk различает увереннее; уменьшите `voice.stop_confidence` (например, до 0.7); всегда работает Ctrl+Alt+Q |

Подробности — в `logs/assistant.log` (запуск с `--debug` пишет ещё больше).

## Тесты

```powershell
uv run pytest
```

Тесты нормализации, числительных, матчера, загрузки команд, голосового цикла, агента
нейросети и интерфейса (на поддельных компонентах; один тест — через настоящий SDK openai
и локальный HTTP-сервер) работают на любой ОС. Тесты в `tests/test_windows.py`
запускаются только в Windows. Три вида тестов выключены по умолчанию:
- открывающие окна и печатающие в них — включаются переменной `JARVIS_DESKTOP_TESTS=1`
  (они перехватывают фокус и закрывают Блокнот). Среди них — окна интерфейса на настоящем
  pywebview и WebView2 (`tests/test_ui_windows.py`): страницы загружаются и обращаются к Python,
  оверлей появляется без фокуса, команда из быстрого чата доходит до конвейера;
- сквозная проверка интерфейса в браузере (`tests/test_ui_e2e.py`, `JARVIS_UI_E2E=1`):
  собранная страница открывается в Chromium, а вместо pywebview работает мост к настоящему
  Python — проверяются настройки нейросети с ключом, проверка связи, быстрый чат.
  Нужны Node.js, `npm ci` в `ui` и `npx playwright install chromium`;
- сквозной тест голоса на настоящих моделях (`tests/test_voice_e2e.py`): Piper
  синтезирует фразы, звук проходит через VAD, Vosk и Whisper. Проверяются активация
  по имени, пропуск фраз без имени, распознавание команд, голосовое подтверждение и «стоп»,
  а в лог печатаются калибровочные данные — включается переменной `JARVIS_E2E=1`,
  нужны скачанные модели.

Живая проверка нейросети — настоящие запросы к выбранному профилю: вызов инструмента и,
если модель понимает картинки, снимок экрана (несколько коротких запросов; платный
провайдер возьмёт за них немного денег):

```powershell
$env:JARVIS_LIVE_LLM = "1"; uv run pytest tests/test_llm_live.py -s
```

Тесты интерфейса на TypeScript: `cd ui; npm test` (и `npm run typecheck`).

Задача «Сборка exe» в CI собирает программу (см. «Сборка exe») и проверяет её: `--self-check`,
скачивание библиотек CUDA (`--download-cuda`: PyPI, sha256, загрузка DLL) и моделей для голоса
(`--download-models` — тем же кодом, что при первом запуске), консольный режим и запуск окон.
Затем выкладывает архив `Jarvis-win-x64`.

При каждом push тесты прогоняются в GitHub Actions: Python — на Windows (вместе с окнами
и голосом на настоящих моделях), интерфейс — на Linux: проверка типов, тесты, сборка
(совпадает ли она с `ui/dist` в репозитории) и сквозная проверка в Chromium.
Живая проверка нейросети там выполняется для тех профилей, чьи ключи есть в секретах
репозитория (Settings → Secrets and variables → Actions): `DEEPSEEK_API_KEY`,
`OPENAI_API_KEY`, `ANTHROPIC_API_KEY`.

## Сборка exe

Сборка — PyInstaller, в Windows, из папки проекта:

```powershell
uv sync --group build
uv run --no-sync pyinstaller --noconfirm --clean packaging/jarvis.spec
```

Результат — папка `dist\Jarvis` (около 500 МБ): `Jarvis.exe`, `JarvisConsole.exe`, `_internal`
и файлы, которые правит пользователь (`config.example.yaml`, `.env.example`, `commands/`,
`README.md`). Проверить сборку без моделей и микрофона: `dist\Jarvis\JarvisConsole.exe
--self-check`. Особенности собранной программы:

- `config.yaml`, `models/`, `logs/` и `timers.json` — рядом с exe, где бы её ни запустили;
- библиотек CUDA в сборке нет (это ещё 2 ГБ, а нужны они только с видеокартой NVIDIA):
  при первом запуске на компьютере с такой видеокартой exe скачивает их с PyPI в папку
  `cuda` рядом с собой — те же колёса `nvidia-*`, что в `uv.lock` (версии и sha256 —
  в `assistant/models.py`, тест сверяет их с `uv.lock`);
- `commands/my.yaml` создаётся из `my.yaml.example` при первом запуске — новая версия,
  распакованная поверх, свои команды не затрёт;
- программы, которые запускает ассистент, не наследуют его папку библиотек `_internal`;
- окна работают на .NET Framework (pythonnet): `Jarvis.exe.config` разрешает загрузку сборок
  из архива, помеченного «из интернета».
